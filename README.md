# ScoutBase для Windows

Официальные установщики и обновления ScoutBase — приложения для сбора публичных сведений о компаниях, работы с локальной базой и экспорта в Excel/CSV.

## Скачать и установить

Откройте [последний выпуск](https://github.com/logIxx01/scoutbase-updates/releases/latest) и скачайте файл **ScoutBase-Setup-…-x64.exe** из раздела Assets.

Установщик предназначен для Windows 10/11 x64 и включает рабочий браузер Chrome и установщик WebView2. После установки доступно демо на 300 уникальных компаний. Полная версия активируется индивидуальным ключом.

## Обновить установленную программу

1. Сделайте резервную копию локальной базы.
2. Приостановите сбор и закройте ScoutBase.
3. Запустите новый Setup и установите его поверх существующей версии.

Обычное обновление сохраняет базу, историю и активацию. Удалять программу перед обновлением не требуется.

Начиная с **0.10.4** ScoutBase проверяет новые выпуски при запуске. Ручная проверка находится в настройках. Версию 0.10.3 и более ранние сборки нужно один раз обновить вручную.

## Состав выпуска

- `ScoutBase-Setup-…-x64.exe` — установщик.
- `stable.json` — подписанное описание версии для проверки обновлений.
- `SHA256SUMS.txt` — контрольные суммы опубликованных файлов.

Этот репозиторий предназначен только для распространения готовых выпусков. Исходный код ScoutBase, инструменты автора, ключи лицензий, ключ подписи и пользовательские базы здесь не размещаются.

Использование программы регулируется условиями лицензии. Наличие открытого репозитория установщиков не предоставляет права на исходный код или перепродажу программы.
